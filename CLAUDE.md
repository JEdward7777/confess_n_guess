# confess_n_guess

A Fibbage-style party game. TypeScript + socket.io server (`src/`), React + Vite
client (`confess_n_guess_client/`).

## Read the harness first

Work on this project is tracked in `harness/`. **Before starting anything, read
`harness/README.md`** — it holds the working rules (including the check-in rule),
`harness/TASKS.md` for what to do next, and `harness/ISSUES.md` for the detail behind
any `CNG-NNN` reference.
